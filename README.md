# 🐂 NMTI — 牛马类型指标

> NiuMa Type Indicator · 4轴组合 · 16型人格

基于职场牛马文化的人格测试，帮你找到自己的「牛马定位」。

## 四大评测维度

| 轴 | 卷型 ← → 躺型 | 工型 ← → 鱼型 | 饼型 ← → 醒型 | 锅型 ← → 嘴型 |
|---|---|---|---|---|
| 投入轴 | 主动推进 | 重视边界 | | |
| 生存轴 | 硬扛补位 | 保存能量 | | |
| 信念轴 | 相信画饼 | 人间清醒 | | |
| 表达轴 | 背锅扛事 | 吐槽输出 | | |

## 16种人格

4轴 × 2态 = 16种组合人格，每种都有独特的职场生存策略。
